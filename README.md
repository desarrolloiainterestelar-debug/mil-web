# Sitio web de MIL

Página web institucional de MIL (inclusión laboral). HTML, CSS y JavaScript, sin dependencias.

## Estructura
- `index.html`: página principal
- `css/estilos.css`: estilos
- `js/main.js`: interacciones (menú, galería, formulario)
- `img/`: imágenes y logos
- `video/`: videos de la galería

## Cómo verla en tu computadora
Abrir la carpeta en VS Code y usar la extensión Live Server (Go Live).

## Formulario de contacto
Los mensajes se envían a través de Formspree.
